    Chat & Bridge Services

    TripSit operates a multi-platform communication suite, uniting IRC, Matrix, Discord, Revolt, and Stoat communities via real-time relay bridges.

    💬 1. IRC Infrastructure (Ergo IRC)

    TripSit's IRC network runs on Ergo, a modern IRC server written in Go with full IRCv3 support.

    • Compose File: docker-compose.irc.yml
    • Container Name: irc
    • Image: ghcr.io/ergochat/ergo:stable
    • Exposed Host Ports:
    • 6667: Standard plaintext IRC port.
    • 6697: Secure TLS IRC port.
    • SSL Certificates: Certificate files are generated by Traefik dynamically and synced to disk via the ssl_export sidecar.

    🟢 2. Matrix Communications Stack

    Matrix provides decentralized, end-to-end encrypted chat capabilities.

    • Compose File: docker-compose.matrix.yml
    Container Name Image Purpose Public URL / Rule
    matrix_synapse matrixdotorg/synapse:latest Matrix Homeserver daemon matrix.tripsit.me
    matrix_webchat vectorim/element-web:latest Element Web Client element.tripsit.me
    matrix_admin awesometechnologies/synapse-admin Web GUI for Synapse server administration matrix-admin.tripsit.me
    matrix_voicechat coturn/coturn:latest Coturn STUN/TURN server for Matrix VoIP calls Internal / TURN ports
    matrix_db bitnami/postgresql:15.4.0 High-performance PostgreSQL database for Synapse Private matrix_db-net
    matrix_redis bitnami/redis:latest Cache layer for Matrix event replication Private matrix_redis-net

    🌉 3. Cross-Platform Chat Bridges

    Revcord Bridge (revcord)

    • Location: /home/moonbear/UAT/revcord
    • Description: A TypeScript bridge using revolt.js that connects Discord and Revolt servers in real-time.
    • Capabilities: Message relay, attachment bridge, replies, embeds, edits, and deletions.
    • Database: SQLite (revcord.sqlite).

    Lightning Bridge (lightning / stoat)

    • Location: /home/moonbear/UAT/lightning & docker-compose.stoat.yml
    • Description: A high-performance Go-based multi-platform bot and bridge system designed to connect Discord, Stoat, Matrix, Spacebar, and Telegram.
    • Database: Dedicated PostgreSQL database (lightning_database).

    Matterbridge (matterbridge)

    • Image: 42wim/matterbridge:stable
    • Description: Relays chat messages across legacy IRC channels, Discord, and Matrix chatrooms.

    ✉️ 4. Mail Server (Stalwart)

    • Compose File: docker-compose.stalwart.yml
    • Container Name: stalwart-mail
    • Image: stalwartlabs/stalwart:latest
    • Host Ports: 25 (SMTP), 587 (Submission), 465 (SMTPS), 143 (IMAP), 993 (IMAPS), 110 (POP3), 995 (POP3S), 4190 (ManageSieve).
    • Public Router Rule: mail.tripsit.io
